[Intro]

Retro Vision Pro is a collection of 23 post-processing effects.
All effects are neat and have lots of customization options, also fully configurable through scripts.
This asset will add various video glitches,displacement and distortion visual effects in your project.

Retro Vision Pro includes 2 packages.				

1. Effects for High Definition Render Pipeline post-processing system. 
2. Effects for Universal Render pipeline.

///

[Setup]

Inside "Assets\RetroVision Pro - CRT & VHS FX" folder you can find 2 unity packages.

1. “URP RetroVision Pro - CRT & VHS FX.unitypackage” for Universal Render.
2. “HDRP RetroVision Pro - CRT & VHS FX.unitypackage” for High Definition Render Pipeline.


After Importing needed package please follow the instructions in Documentation file.

///

[SRP support]

URP: Native support via Render feature, so effects dont rely on any post processing system.
(HDRP) Retro Vision Pro includes custom Post-processing effects pack for HDRP integrated post-processing system.
